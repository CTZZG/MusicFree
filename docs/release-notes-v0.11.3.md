# MusicFree v0.11.3

修复 Live Update 卡片偶尔留下一大块空白；插件管理和关于页重新整理。

## 下载

需要 Android 8.0 及以上。大部分手机下载 **arm64-v8a** 版；不确定时下载 **universal** 版（体积较大，所有设备通用）。

- `…-app-arm64-v8a-release.apk`：大部分手机
- `…-app-armeabi-v7a-release.apk`：较老的 32 位手机
- `…-app-universal-release.apk`：通用版
- `…-app-x86_64-release.apk`、`…-app-x86-release.apk`：模拟器

各文件的 SHA256 校验值见 `SHA256SUMS.txt`。

## 修复

- **Live Update 卡片不再留白**：开着 Live Update 歌词时，在前奏、间奏或切歌之后，荣耀手机的实况卡片有时下面按钮那块一片空白。现在这段时间卡片照常显示，标题换成歌名，下一句歌词到了再显示歌词。
- **顶部按钮更好点**：页面右上角、左上角的按钮，点击范围扩大到整个标题栏的高度。

## 改进

- **插件管理**：去掉右上角的“⋮”菜单和右下角的悬浮按钮。右上角的“+”用来安装插件（从本地、从网络，或导入 LX 自定义源）；订阅设置、插件排序、LX 自定义源、更新订阅、更新全部插件、诊断和卸载全部插件都直接列在页面上。
- **关于**：改为介绍这个修改版：版本、检查更新、历史版本、源代码，以及可以复制的构建信息（播放器一栏显示 mpv 的版本）。致谢原作者猫头猫的 MusicFree，并注明本应用基于它修改、以 GNU AGPL-3.0 开源。
- 应用出错时的反馈入口改为本项目的主页。

## 说明

- 开着 Live Update 歌词时，没有歌词的歌也会显示 Live Update 卡片，标题是歌名。不想要的话，可以在设置里关掉 Live Update 歌词。
