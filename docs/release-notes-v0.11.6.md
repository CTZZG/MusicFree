# MusicFree v0.11.6

修复带标签的 OGG 文件写不进封面，以及桌面歌词设置出错时闪退、开启失败时提示不准确的问题。

## 下载

需要 Android 8.0 及以上。大部分手机下载 **arm64-v8a** 版；不确定时下载 **universal** 版（体积较大，所有架构通用）。

- `…-app-arm64-v8a-release.apk`：大部分手机
- `…-app-armeabi-v7a-release.apk`：较老的 32 位手机
- `…-app-universal-release.apk`：通用版
- `…-app-x86_64-release.apk`、`…-app-x86-release.apk`：模拟器

各文件的 SHA256 校验值见 `SHA256SUMS.txt`。

## 改进与修复

- **带尾标签的 OGG 也能写入封面**：完整的 OGG 文件末尾带 ID3v1 或 APE 标签时，0.11.5 会放弃写入封面；现在照常写入，并原样保留这些标签。损坏或不完整的文件仍然拒绝，原文件不变。
- **桌面歌词设置不再闪退**：调整位置、宽度、字号、颜色等出错时不再导致应用退出，失败会写入错误日志。没有显示中的歌词窗口时调整位置和宽度，只保存设置，下次显示时生效。
- **开启失败的提示更准确**：只有确实没有悬浮窗权限时，才提示去系统设置打开；其他原因的失败会说明已关闭，可在错误日志查看。保存的歌词设置里有无效值时忽略该项，不再导致开启失败。

## 验证范围

Android 14 模拟器完成播放、下载、数据迁移及锁屏、Doze、省电等全量回归；Android 16 模拟器检查实际引擎进度、暂停意图、慢加载、播放服务启动，以及桌面歌词设置、悬浮窗权限处理和带尾标签的 OGG 封面写入。模拟器检查不代表物理音频输出，本次修复没有在真机上逐项验证。
