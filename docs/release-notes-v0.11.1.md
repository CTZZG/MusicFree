# MusicFree v0.11.1

修复版本：断网点歌没有提示、换音质从头播、底部标签栏偶尔被播放条盖住。

## 下载

需要 Android 8.0 及以上。大部分手机下载 **arm64-v8a** 版；不确定时下载 **universal** 版（体积较大，所有设备通用）。

- `…-app-arm64-v8a-release.apk`：大部分手机
- `…-app-armeabi-v7a-release.apk`：较老的 32 位手机
- `…-app-universal-release.apk`：通用版
- `…-app-x86_64-release.apk`、`…-app-x86-release.apk`：模拟器

各文件的 SHA256 校验值见 `SHA256SUMS.txt`。

## 修复

- **断网时点歌会有提示**：没有网络时点一首歌，几秒后会回到之前那首，并提示“播放未成功”；网络恢复后在提示里点“重试”就能播。以前会悄悄回到之前那首，什么提示都没有。
- **切换音质不再从头播**：播放中换音质会接着原来的进度播，播放地址过期、重新获取时也一样。重新打开应用后，通知栏和锁屏上显示的是上次暂停的进度，不再是 0 秒。
- **底部标签栏不会再被播放条盖住**：以前偶尔会出现底部的“首页、搜索、资料库、设置”不见了、只剩播放条的情况（比如从其他页面返回后马上锁屏或切到别的应用），要进出一次别的页面才恢复。
