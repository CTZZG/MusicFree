# MusicFree v0.15.1

优化下载断点续传，修复观看 MV、后台播放和清理缓存时的几处问题。

## 升级前请注意

- 需要 Android 14 或更高版本。Android 13 及以下请继续使用 v0.11.6。
- 直接覆盖安装就能保留歌单、设置和插件。先卸载会清空这些内容。

## 改进与修复

- 下载暂停后再继续时，会从已下载的位置接着下；如果远端音频文件已变化，会自动重新完整下载，避免拼出损坏文件。
- 修好了观看 MV 时退到后台返回歌曲、切歌或单曲循环重播时，播放进度、暂停状态和倍速偶尔不对的问题。
- 修好了横屏全屏看 MV 时控制区域贴边被刘海遮挡，以及切换英文或繁体中文后部分提示未翻译的问题。
- 在「基本设置 → 缓存」清理音乐缓存时，不会再误删正在播放或已在播放队列中的外部导入音频。
- 修好了通知栏倍速进度跳变及车机连接状态偶尔延迟错乱的问题；如果在车机或后台播放时仍遇到异常，可在「基本设置 → 开发选项 → 复制播放诊断」后反馈。
- 修复了若干媒体文件解析与外部链接处理的安全问题。

## 下载

大多数安卓手机选 **arm64-v8a**。拿不准就选 **universal**，这个安装包大一些。

32 位手机选 **armeabi-v7a**。**x86** 和 **x86_64** 供对应架构的设备或模拟器使用。文件校验值在 `SHA256SUMS.txt` 里。
