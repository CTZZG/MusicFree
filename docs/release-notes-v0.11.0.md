# MusicFree v0.11.0

## 下载

需要 Android 8.0 及以上。大部分手机下载 **arm64-v8a** 版；不确定时下载 **universal** 版（体积较大，所有设备通用）。

- `…-app-arm64-v8a-release.apk`：大部分手机
- `…-app-armeabi-v7a-release.apk`：较老的 32 位手机
- `…-app-universal-release.apk`：通用版
- `…-app-x86_64-release.apk`、`…-app-x86-release.apk`：模拟器

各文件的 SHA256 校验值见 `SHA256SUMS.txt`。

## 升级前请注意

- **播放失败时会自动换到其他来源**：“播放失败时尝试更换音源”改为默认开启。只会换到歌名（包括 Live、伴奏等版本说明）、歌手都一致，时长也对得上的同一首歌，不会换成翻唱或别的版本；换源播放时，播放页歌手旁的来源标签显示“改用 XX”。不需要的话可以在 设置 → 基本设置 → 播放 里关掉。
- **应用内的“检查更新”现在会提示本分支的新版本**，从这一版起可以直接在应用里升级。

## 新功能

- **自动换源并记住**：一首歌的来源取不到播放地址时，自动到其他来源找同一首歌接着播，并记住能播的来源。之后再放这首歌、切歌、后台自动连播、播放地址过期、切换音质，都会直接用它。
- **播放统计**：设置 → 基本设置 → 开发选项 → 播放统计，可以看到最近 7 天各来源播放了多少次、换了几次来源、失败了几次以及失败原因，还能一键复制。只记来源和结果，不记歌名，只保存在本机。
- **检查更新**：按手机的 CPU 架构直接下载对应的安装包，也可以打开发布页自己选；连不上时会提示“检查更新失败”，不再误报“已是最新版本”。

## 改进与修复

- 后台自动连播遇到放不了的歌时，也会换到其他来源继续播，不再停在这首。
