# 🎵 MusicFree v0.7.3

## 📱 下载选项

**推荐下载（适用于所有 Android 设备）：**

- **Universal APK**：前往 [MusicFree v0.7.3 Release 页面](https://github.com/CTZZG/MusicFree/releases/tag/v0.7.3) 下载 `MusicFree-0.7.3-<sha>-app-universal-release.apk`

**按设备架构下载（体积更小）：**

- **ARM64（推荐）**：`app-arm64-v8a-release.apk`，适用于大部分现代 Android 设备
- **ARM32**：`app-armeabi-v7a-release.apk`，适用于较老的 Android 设备
- **x86_64**：`app-x86_64-release.apk`，适用于 x86_64 模拟器
- **x86**：`app-x86-release.apk`，适用于 x86 模拟器

Release 页面同时提供 SHA256 校验文件、构建信息与混淆映射文件。

## ⚠️ 升级提示

- 本版本目标 SDK 升级到 36。首次播放本地歌曲时会请求“音乐和音频”权限；拒绝后本地音乐功能将不可用。
- DSF、ASF 等系统媒体库未识别的格式，可通过“本地音乐 → 左上角菜单 → 扫描文件夹”授权目录并扫描。授权会持久保存，重新扫描不会重复添加已有歌曲。
- 部分音源插件仍使用公网 HTTP 接口。如果榜单为空或封面不显示，可在“设置 → 基本设置 → 网络”中开启“允许插件使用 HTTP”；开启前请阅读风险提示。
- WebDAV 仍推荐使用 HTTPS。已有兼容需求时可在确认传输风险后使用用户配置的 HTTP 地址。

## 🔄 重点更新

### 投屏与播放

- 新增 Google Cast 支持，可将音乐投到 Chromecast、Google TV 等设备。
- 投屏连接后，播放、暂停、切歌与播放列表操作会路由到投屏设备，本地播放自动静音。
- Cast 初始化改为共享单航班并支持失败重试；只有 Nitro 后端初始化成功后才显示投屏入口，初始化失败不会阻塞应用启动。
- 播放器内核升级至 Nitro Player 1.5.0，并修复部分音源链接因协议处理不兼容而无法播放的问题。
- 恢复 Nitro 下载管理器依赖的 WorkManager 自动初始化，避免冷启动或下载组件初始化失败。

### 均衡器

- Nitro 后端均衡器已接入真实 DSP，拖动滑杆会实际改变音效。
- 频段调整为标准十段（31 Hz～16 kHz），界面频率、预设与底层 DSP 保持一致。
- MPV 后端不支持该 DSP 时自动隐藏均衡器入口，避免出现无效控制项。

### 推荐、插件与网络

- 修复推荐歌单在相同标签 ID 但请求参数变化时不刷新的问题；切换标签后，旧分页响应不会再污染新列表。
- 修复部分插件搜索、榜单、歌单以及内置网易云、LRCLIB 歌词请求失败的问题。
- 修复 crypto-js 等依赖原型继承的插件加密能力被只读 facade 破坏的问题。
- 新增“允许插件使用 HTTP”开关，并修复公网 HTTP 封面、下载与封面嵌入失败的问题。
- 插件管理页只保留最近 24 小时的诊断记录，新增“清除诊断记录”，测试搜索卡住后可以取消。

### 本地音乐、下载与备份

- 修复升级后本地歌曲因权限变化无法播放的问题；缺少权限时会主动请求并给出提示。
- 授权文件夹后可扫描 DSF、ASF 等系统未识别格式；跨 MediaStore/SAF 扫描会合并同一文件，避免重复条目。
- 修复音乐标签与封面写回过程中可能截断或损坏原文件的问题。
- WebDAV 密码迁移失败时会在设置页提示并支持重试；备份导出可以中途退出。
- 修复用户配置的 HTTP WebDAV 上传失败问题，HTTP 与 HTTPS 共用一致的请求与重定向处理路径。

### 安全与工程质量

- 插件安装和更新继续强制使用 HTTPS；MusicFree 提供的插件网络 API 默认拒绝本机、内网、链路本地及保留地址。
- 能力确认弹窗明确说明插件以应用自身权限运行，上述 API 收敛不是安全沙箱，请只安装可信来源的插件。
- 修复 `package.json` 与锁文件不一致导致 GitHub Actions 在 `npm ci` 阶段失败的问题，并验证隔离环境可重复安装及重放全部补丁。
- 将 `file-type` 升级到 21.3.4、`uuid` 升级到 11.1.1；为旧 Jimp 接口增加兼容补丁和真实行为门。当前锁文件在 npm 官方 registry 审计结果为 0 个已知漏洞。
