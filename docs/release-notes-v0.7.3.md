# 🎵 MusicFree v0.7.3

### 📱 下载选项

**推荐下载 (适用于所有设备):**
- **Universal APK**: 前往 [MusicFree v0.7.3 Release 页面](https://github.com/CTZZG/MusicFree/releases/tag/v0.7.3) 下载 `MusicFree-0.7.3-<sha>-app-universal-release.apk`

**按设备架构下载 (体积更小):**
- **ARM64 (推荐)**: `app-arm64-v8a-release.apk` - 适用于大部分现代 Android 设备
- **ARM32**: `app-armeabi-v7a-release.apk` - 适用于老版本 Android 设备
- **x86_64**: `app-x86_64-release.apk` - 适用于 x86_64 模拟器
- **x86**: `app-x86-release.apk` - 适用于 x86 模拟器

Release 页面同时提供 SHA256 校验文件、构建信息与混淆映射文件。

### ⚠️ 升级提示

- 本版本目标 SDK 升级到 36。**首次播放本地歌曲时会请求「音乐和音频」权限，请点击允许**，否则本地歌曲无法播放。
- 如果你的本地歌曲里有 **DSF、ASF 等格式**，或存放在系统未识别的目录，请进入 **本地音乐 → 左上角菜单 → 扫描文件夹**，选择你的音乐目录并授权一次。授权会长期保留，收藏、歌单和播放历史都不会丢失。
- 部分音源插件的榜单、歌单和封面接口仍使用 HTTP。如果发现榜单为空或封面不显示，请到 **设置 → 基本设置 → 网络 → 允许插件使用 HTTP** 打开该开关。

### 🔄 更新内容

1. 【投屏】新增 Google Cast 投屏支持，播放页顶部出现投屏按钮，可将音乐投到 Chromecast、Google TV 等设备
2. 【投屏】投屏连接后播放、暂停、切歌与播放列表操作会自动路由到投屏设备，本地声音自动静音
3. 【投屏】网络中没有可用投屏设备时按钮自动隐藏；使用 MPV 播放器时不显示该功能
4. 【架构】播放器内核升级至 Nitro Player 1.5.0
5. 【优化】关闭未使用的后台任务框架自启动，减少每次冷启动的额外初始化开销
6. 【均衡器】均衡器现已真正生效，拖动滑杆会实际改变音效，不再是只有界面没有效果
7. 【均衡器】调整为标准十段（31Hz ~ 16kHz），滑杆标注的频率就是实际生效的频率，预设同步更新
8. 【均衡器】使用 MPV 播放器时自动隐藏入口，避免出现调了没反应的情况
9. 【插件】修复部分插件搜索、榜单、歌单请求失败的问题
10. 【插件】修复部分音源插件因加密解析失败而无法使用的问题
11. 【插件】新增「允许插件使用 HTTP」开关（设置 → 基本设置 → 网络），开启后榜单、歌单和封面恢复正常
12. 【插件】修复 HTTP 封面图无法显示的问题
13. 【插件】修复内置网易云、LRCLIB 歌词搜索失效的问题
14. 【插件】插件管理页的报错记录只显示最近 24 小时，并新增「清除诊断记录」入口
15. 【插件】修复插件测试搜索卡住后无法取消的问题
16. 【本地音乐】修复升级后本地歌曲全部无法播放的问题，缺少权限时会主动申请并给出提示
17. 【本地音乐】授权文件夹后，DSF、ASF 等系统不识别的格式可以正常扫描和播放
18. 【本地音乐】重新扫描会直接更新已有歌曲的路径，不会产生重复条目，收藏和歌单不受影响
19. 【下载】修复音乐标签与封面写回时可能损坏原文件的问题
20. 【下载】修复 HTTP 音源无法下载、无法嵌入封面的问题
21. 【备份】WebDAV 密码迁移失败时会在备份设置页给出提示并支持一键重试
22. 【备份】备份导出过程中可以中途退出，不再卡住无法返回
23. 【备份】修复 HTTP WebDAV 上传必定失败的问题
24. 【播放】修复部分音源因链接协议被拦截而无法播放的问题
25. 【安全】插件安装与更新始终只允许 HTTPS；无论是否开启 HTTP 开关，都不会允许插件访问本机和内网地址
26. 【安全】能力确认弹窗如实说明插件以应用自身权限运行，请只安装可信来源的插件
27. --------以上为 v0.7.3 新特性--------
28. 【数据】并发下载自动预留唯一目标路径，避免同名任务互相覆盖
29. 【缓存】修复缓存淘汰与更新交错时误删新值或新文件的问题
30. 【歌单/插件】歌单删除和插件升级采用原子提交，失败时保留原数据与旧插件
31. 【备份】恢复报告按实际新增条目计数，重复歌曲不再被误报为新增
32. 【播放】播放器启动先完成后端锁定与就绪门控，避免冷启动时误触发错误播放器后端
33. 【播放】收敛 MPV Service 销毁重建、排队命令和异步查询时序，迟到响应不再覆盖当前歌曲状态
34. 【歌词】LyricManager 初始化幂等、订阅可释放，歌词只更新当前活动播放器后端
35. 【安全】WebDAV 与插件安装统一 HTTPS、私网、重定向和凭据校验，外部脚本安装增加确认
36. 【隐私】遥测默认关闭，只有用户明确开启才发送；异常与调试日志改为最小化输出
