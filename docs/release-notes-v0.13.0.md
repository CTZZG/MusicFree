# MusicFree v0.13.0

新增音量平衡、车载蓝牙歌词和 Android Auto 列表，并在手机上记录崩溃原因。

## 升级前请注意

- **仍需 Android 14（API 34）及以上**。Android 13 及以下请继续使用 v0.11.6 或更早的适用版本。
- Android 14 及以上请覆盖安装。不要先卸载旧版，卸载会清除应用里的歌单、设置和插件。

## 新功能

- **音量平衡（ReplayGain）**：基本设置 → 播放 → 音量平衡，可选关闭（默认）、按单曲、按专辑。按歌曲文件里的 ReplayGain 标签调整音量，让不同歌曲听起来差不多响，改了立刻生效。没有这个标签的歌（多数在线音源）音量不变。
- **车载蓝牙歌词**：基本设置 → 歌词 → 车载蓝牙歌词（默认关）。连着蓝牙音频或 Android Auto 时，把当前这句歌词放在歌名的位置，车机屏幕上就能看到；这期间手机上的媒体卡片也显示歌词。
- **Android Auto 里浏览“我喜欢”“最近播放”**：车机上除了当前播放队列，还能打开这两个列表（各显示最多 200 首）。点其中一首，用整个列表替换播放队列，从这首开始播。
- **记录崩溃原因**：应用崩溃、无响应或被系统结束时，原因记在手机上，在 基本设置 → 开发选项 → 复制播放诊断 里一并给出，方便反馈问题。记录不联网、不上传，链接参数、Cookie、token 等会遮掉；“清空日志”一并清除。

## 维护

- 升级 follow-redirects（1.16.1）和 launch-editor（2.14.2），处理三条新公布的高危安全公告。这两个包都不进应用代码。
- 发版检查新增：64 位原生库必须按 16 KB 内存页对齐。

## 下载

大部分手机下载 **arm64-v8a** 版；不确定时下载 **universal** 版（体积较大，包含所有架构）。

- `…-app-arm64-v8a-release.apk`：大部分手机
- `…-app-armeabi-v7a-release.apk`：32 位系统的手机
- `…-app-universal-release.apk`：通用版
- `…-app-x86_64-release.apk`、`…-app-x86-release.apk`：模拟器

各文件的 SHA256 校验值见 `SHA256SUMS.txt`，构建来源和签名记录见 `android-build-info.txt` 及正式构建日志。

## 验证范围

同一产品代码的 R8 Release 候选在 Android 14 模拟器完成 117 项全量检查，覆盖播放、下载、迁移、锁屏、Doze、省电，以及这一版的崩溃记录（Java 崩溃和原生崩溃都记下、清空后不再显示）。在 Android 17 模拟器上打开最严的后台音频加固，跑锁屏、Doze、省电和音频焦点打断，28 项全部通过，本应用没有被加固拦下。Android 16 模拟器检查通过。

**音量平衡、车载蓝牙歌词和 Android Auto 列表只有单元测试**：模拟器上没有蓝牙和 Android Auto，没有在真机或车机上验证。模拟器检查不代表物理音频输出，本轮没有新增真机验收。
