# MusicFree v0.11.4

改善切歌、暂停和换音质的稳定性，修复下载收尾与旧数据迁移问题。

## 下载

需要 Android 8.0 及以上。大部分手机下载 **arm64-v8a** 版；不确定时下载 **universal** 版（体积较大，所有架构通用）。

- `…-app-arm64-v8a-release.apk`：大部分手机
- `…-app-armeabi-v7a-release.apk`：较老的 32 位手机
- `…-app-universal-release.apk`：通用版
- `…-app-x86_64-release.apk`、`…-app-x86-release.apk`：模拟器

各文件的 SHA256 校验值见 `SHA256SUMS.txt`。

## 修复

- **切歌不再无限等待插件**：单次取播放地址有十五秒期限；同一轮切歌不会向已经超时的来源再等一轮。其他可用来源仍会按原规则尝试，失败后保留处理入口，下一次播放或重试可以重新取源。
- **主动暂停一直生效**：切歌等待、取源失败后回到原歌、新歌装好、自动播放补偿，以及暂停后拖动进度，都不会把主动暂停的歌重新播放。通知栏、锁屏、耳机和应用内暂停采用相同的播放意图规则。
- **临时打断后按原意图恢复**：其他应用临时占用音频焦点时，音乐保持暂停；系统还回焦点后，打断前正在播放的会接着播。打断前已经暂停，或打断期间又主动暂停过的，会继续停着。
- **慢速换音质保留最新进度**：等待新音质地址期间原音源继续播放，应用新源前重新读取位置；期间暂停或拖动进度的结果也会保留，避免回到请求开始时的位置。
- **下载失败保护已有文件**：收尾记录写不进磁盘时停止写最终文件，任务标为失败；首次收尾失败只清理这次下载的缓存，保留原有歌曲、歌词和歌单。下载中断后的恢复继续按已有收尾记录处理。
- **升级后的数据迁移更可靠**：迁移期间删除或清空的数据不会被旧数据重新带回来；修复插件名含空格、中文或加号时附加信息保存和迁移异常。歌曲附加信息载入后，已打开的界面会更新；退出时保存最后取得的播放进度。
- **编辑按钮更好点**：歌曲批量编辑和歌单编辑的保存按钮使用更大的点击区域。

## 验证范围

Android 14 模拟器已检查切歌、暂停/临时打断、下载/迁移故障及锁屏/Doze/省电流程；
Android 16 模拟器另检查通知进度及慢速切歌、换音质和临时打断时的实际播放器进度与暂停状态。
真机厂商的后台限制、真实视频应用兼容性仍未完成验收；模拟器的强制 Doze 不代表真机处理器实际休眠。
