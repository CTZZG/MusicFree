# MusicFree v0.14.0

新增歌曲与歌词分享、首页排序和当前播放信息，并改善歌词显示与备份恢复。

## 升级前请注意

- 需要 Android 14 及以上。Android 13 及以下请继续使用 v0.11.6。
- 直接覆盖安装即可。不要先卸载，卸载会清空歌单、设置和插件。
- 建议升级前导出并保留一份备份；如需回退旧版，请使用旧版导出的备份。

## 新功能

- 播放页和歌曲菜单可分享歌曲卡片，或选取最多四句歌词生成图片，支持附带译文、保存到相册和发送给其他应用。
- “首页顺序”可调整继续听、推荐与榜单、最近播放和快捷入口的位置，也可恢复默认顺序。
- 当前歌曲菜单新增“当前播放信息”，分别显示歌曲原来源、实际播放来源、插件音质标签和文件的编码、采样率等信息。

## 改进与修复

- 分享准备阶段可取消并重试，避免重复点击造成重复分享；修复宽字符和组合表情在分享图片中的截断。
- 歌词页保留常用字号和译文入口，其余操作收纳到“歌词工具”；歌词加载完成后，分享面板可重新载入同曲歌词。
- 修复英文逐字歌词的长音强调，以及大字体下播放信息和分享操作的布局。
- 修复迷你播放器拖动后停住再松手时切歌方向相反，以及动画取消后仍然切歌的问题。
- 配置或歌单读取失败时保留原文件并提示重新读取，避免把内容误当作空数据保存。
- 备份恢复保留歌单封面、描述、添加时间和歌曲顺序，并恢复分组、置顶、首页顺序及列表布局；旧备份仍可导入。
- 修复部分通过网址恢复备份失败的问题。

## 下载

大部分手机下载 **arm64-v8a** 版；不确定就下载 **universal** 版（体积较大）。

- `…-app-arm64-v8a-release.apk`：大部分手机
- `…-app-armeabi-v7a-release.apk`：32 位系统的手机
- `…-app-universal-release.apk`：通用版
- `…-app-x86_64-release.apk`、`…-app-x86-release.apk`：模拟器用

各文件的 SHA256 校验值见 `SHA256SUMS.txt`。
