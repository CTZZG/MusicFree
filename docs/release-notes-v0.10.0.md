# MusicFree v0.10.0

## 下载

需要 Android 8.0 及以上。大部分手机下载 **arm64-v8a** 版；不确定时下载 **universal** 版（体积较大，所有设备通用）。

- `…-app-arm64-v8a-release.apk`：大部分手机
- `…-app-armeabi-v7a-release.apk`：较老的 32 位手机
- `…-app-universal-release.apk`：通用版
- `…-app-x86_64-release.apk`、`…-app-x86-release.apk`：模拟器

各文件的 SHA256 校验值见 `SHA256SUMS.txt`。

## 升级前请注意

- **歌词不再跟着系统字体放大**，只按歌词页自己的字号显示。以前靠调大系统字体来放大歌词的，升级后请在歌词页的字号设置里选大一档（新增了三个更大的档位）。
- **更多页面的文字会跟着系统字体大小变化**：播放页、搜索、推荐歌单、榜单、各详情页，以及歌曲选项、播放队列、音质等弹出面板。
- **搜索单曲默认显示“全部来源”**：各来源的结果排在一起；同一首歌有多个来源时，可以在歌下面的“其他来源”里选择用哪个来源播放。
- **资料库里长按歌单会打开菜单**（置顶、分组、删除），不再直接删除。
- **“我喜欢”移到了资料库上方的入口里**，“我的歌单”只显示自己创建和导入的歌单。
- 应用内的“检查更新”不会提示本分支的新版本，请到本页面下载。

## 新功能

- **播放失败时可以处理**：播放失败后会留下提示，点开能看到原因，可以重试、换个音质、找其他来源或检查插件设置；插件授权失效时会直接提示，不再逐个尝试其他音质。
- **显示实际音质**：音质面板会标出当前歌曲实际播放的音质。
- **编辑播放队列**：可以上移、下移、设为下一首；删除或清空后可以撤销。
- **搜索“全部来源”**：一次看到所有来源的结果，加载失败的来源可以单独重试。
- **整理歌单**：“我的歌单”可以按名称搜索、置顶、分组，并可在网格和列表之间切换。
- **歌词字号**：新增三个更大的字号，设置时可以实时预览，也可以一键恢复默认。
- **榜单预览**：榜单改为三列卡片，部分榜单直接显示前几首歌。

## 改进与修复

- 修复在后台通过通知栏或锁屏切歌后，回到 App 又跳回之前那首歌的问题。
- 修复关闭播放通知后，通知又自己重新出现的问题。
- 播放页的封面和文字不再压到进度条；横屏时封面和歌名并排显示，不再挡住导航栏；从歌词页切回封面时不再闪出空白。
- 调大系统字体后，播放页的导航栏、歌名和播放时间不再显示不全。
- 底部标签栏和迷你播放器改用真正的毛玻璃效果，背后的文字不再透出来。
- 修复返回时跳过上一页的问题。
- 权限页改为申请“音乐和音频”权限，不再跳到无法开启的“所有文件访问”。
- 修复开启代理（fake-ip 模式）时封面加载不出来、无法下载的问题。
- 插件页不再把正常记录显示成“最近错误”；插件设置项的名称和说明可以完整显示。
- 停用插件后，首页音源和搜索来源立即更新；“推荐歌单 · 全部”打开首页当前选中的音源。
- 修复滚动到列表底部后第一次点击无效，以及推荐歌单的封面和标题被裁掉的问题。
- 首页更紧凑，卡片大小按屏幕宽度调整。
- 读屏软件朗读搜索标签时使用界面语言。
- 基本设置里不再重复显示 Last.fm。
