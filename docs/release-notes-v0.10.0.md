# 🎵 MusicFree v0.10.0

## 📱 下载选项

**推荐下载（Android 8.0 及以上）：**

- **Universal APK**：前往 [MusicFree v0.10.0 Release 页面](https://github.com/CTZZG/MusicFree/releases/tag/v0.10.0) 下载 `MusicFree-0.10.0-<短 SHA>-app-universal-release.apk`

**按设备架构下载（体积更小）：**

Release 页面同时提供 SHA256 校验文件、构建信息与混淆映射文件。

## ⚠️ 升级提示

- **歌词不再跟着系统字体放大。** 歌词页只按自己的字号显示，字号面板新增三个更大的档位（共七档），带实时预览和“恢复默认”。以前靠系统大字体看大歌词的，升级后请在歌词页的字号设置里选大一档。
- **更多页面的文字跟着系统字体大小。** 播放页、搜索、推荐歌单、榜单、歌单／榜单／专辑详情、自己的歌单详情、歌手详情，以及歌曲选项、加入歌单、播放队列、音质等面板，会随系统“字体大小”放大；首页、资料库、设置等页面暂时不变。
- **搜索单曲默认进入“全部来源”总览。** 各来源的结果交错排在一起；歌名、歌手、专辑、时长完全相同的歌合成一条，下面的“其他来源”可以选用哪个来源播放。只想看某个来源，点上面的来源标签。
- **资料库里长按歌单变成菜单。** 长按或点歌单右边的 ⋮，可以置顶、设置分组、删除（删除仍会确认）；以前长按是直接弹出删除确认。
- **“我喜欢”移到资料库上面的入口里。** 它是播放页点 ♥ 收歌的歌单，不能删除和改名；“我的歌单”只列自己建的和导入的歌单。
- 应用内的“检查更新”读的是上游 maotoumao/MusicFree 的版本信息，不会提示本分支的新版本，请在本仓库 Release 页面下载。

## 🔄 重点更新

### 播放

- 播放失败后留一个入口，点开能看到原因，并可以重试、换个音质再试、找其他来源或检查插件设置；插件授权失效时，不再接着尝试同一插件的其他音质。
- 音质面板标出这首歌实际拿到的音质。
- 播放队列里每首歌可以上移、下移、设为下一首；删除和清空可以撤销一步。删除正在播放的歌时如果正好有别的操作，按最新的队列重新处理，这次删除不会丢掉。
- 修复在后台从通知栏、锁屏切歌后，回到 App 又退回之前那首。
- 关掉播放通知后，封面重试不再把通知重新弹出来。

### 搜索

- 新增“全部来源”总览（见升级提示）。列表顶上只列出失败的来源（超时或加载失败），可以单独重试。
- 停用插件后，搜索的来源标签立即更新。
- 搜索结果的类别、来源标签按界面语言朗读。

### 资料库与歌单

- “我的歌单”可以按名称搜索、置顶、分组，网格和列表两种视图可以切换，选择会记住。
- 歌单右边的 ⋮ 改成和歌曲列表一样的图标；还没有自己的歌单时，直接给出新建和导入。
- “我喜欢”空着时说明在播放页点 ♥ 收歌；英文界面下标题也跟着界面语言。

### 首页与榜单

- 首页顶部更紧凑；首页和资料库的卡片按屏宽缩小，页边距统一。
- 榜单改为三列方卡，有现成数据时直接显示几首歌的预览。
- “推荐歌单 · 全部”打开首页正在看的音源；停用插件后首页音源立即更新。

### 播放页

- 封面按实际空间收紧，歌名和迷你歌词不再压到进度条；横屏时封面和歌名并排，不再盖住导航栏。
- 从歌词页切回封面时不再露出空的封面框。
- 系统字体放大后，导航栏、歌名、进度时间不再溢出。

### 其他修复

- 底部标签栏和迷你播放器改用真正的模糊效果，背后的内容不再透出来。
- 打开同名页面时新开一页，返回不再跳过上一页。
- 权限页改为管理“音乐和音频”权限，不再跳到灰掉的“所有文件访问”。
- 使用代理（fake-ip）时，封面、下载等请求不再被拦截。
- 插件卡片和诊断报告不再把迁移、能力记录算成“最近错误”；插件的设置表单完整显示名称和说明。
- 滚到列表底部后的第一次点击不再失效；推荐歌单网格的封面和标题不再被裁掉。
- 基本设置里不再重复列出 Last.fm。

### 工程

- Android 原生单元测试进入 Beta、正式版和 PR 检查。
- 新增用真实组件排版的布局测试，检查文字截断、点击范围、被底栏遮挡等，共 1225 项。
- ESLint 警告按规则设上限，只许减少；补丁打不上、依赖查询失败时，检查不再悄悄通过。
