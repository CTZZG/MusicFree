# 🎵 MusicFree 0.7.1

0.7.1 重点修复网络插件歌曲在 MPV 后端切换时的竞态与失败恢复问题，并继续完善沉浸式播放详情页的操作反馈。手动切歌现在会等待后端确认目标歌曲，上滑切换下一曲也有完整的页面联动动画和更清晰的入口提示；圆形封面布局、Mini 歌词与切歌背景同步也得到进一步优化。

## 📱 下载

- [前往 MusicFree 0.7.1 Release 页面](https://github.com/CTZZG/MusicFree/releases/tag/v0.7.1)

Release 页面将提供 Universal、ARM64、ARM32、x86 和 x86_64 APK，以及 SHA256 校验、构建信息与混淆映射文件。

## 🎧 网络歌曲切换稳定性

1. MPV 手动切歌增加串行状态门控，旧歌曲迟到的 `trackChanged`、自然结束和播放错误事件不再覆盖当前切歌结果。
2. 获取插件播放地址并推送到后端后，会等待 MPV 确认目标歌曲已经激活，再提交播放队列和界面状态。
3. 连续快速切歌时，过期请求会被取消，只有最后一次仍然有效的切歌操作可以更新当前歌曲。
4. 插件无法返回有效播放地址、后端加载失败或目标歌曲未能确认时，会恢复原歌曲、原播放位置和原播放/暂停状态。
5. 后端恢复流程会清理未完成的待切换状态，避免失败请求继续影响后续播放。

## ✨ 沉浸式播放详情

1. 竖屏详情页支持从底部区域上滑切换下一曲，并扩大播放控件下方的手势判定范围。
2. 上滑过程由局部控件动画升级为整页联动反馈：内容整体跟随手势上移，背景同步产生轻微视差缩放与明暗变化。
3. 达到阈值后播放页会完成上冲动画再切歌；未达到阈值或切歌失败时平滑回弹，操作结果更直观。
4. 底部入口改为双上箭头交替明灭提示，播放控件整体上移，为手势提供更充分的操作空间。
5. Hero 主视觉比例继续微调，歌曲信息、歌词和播放区域的纵向关系更加紧凑。

## 💿 圆形封面与沉浸背景

1. 圆形封面使用独立的竖屏流式布局和响应式尺寸，封面不会再覆盖顶部歌曲信息，底部功能菜单也不会与播放控件重叠。
2. 圆形模式的 Mini 歌词整体下移并扩大展示窗口，当前行字号提升，上下文行增加呼吸感，减少歌曲信息附近的拥挤与功能栏上方的大片空白。
3. 长屏使用更舒展的歌词间距，短屏自动切换为紧凑规格；方形 Hero、横屏和完整歌词详情页继续使用原有布局。
4. 切歌时会预取新封面并并行提取背景主色，封面、模糊背景和渐变颜色作为同一视觉代际提交，降低背景下半区慢一拍或短暂分层的观感。
5. 沉浸背景图片缓存与过渡时间同步优化，慢速取色只会更新当前歌曲，不会把上一首歌曲的颜色重新带回界面。

## 🎤 歌词详情布局

1. 歌词详情页的收藏、歌词、字体和歌词位置操作栏同步上移，为底部播放控件及上滑手势区域预留空间。
2. 竖屏与横屏分别使用对应间距，避免修复竖屏重叠时给横屏引入多余留白。

## 🖥️ 桌面歌词逐字高亮

1. 桌面悬浮歌词支持按音源提供的真实逐字时间轴推进，已唱字符与未唱字符使用不同明暗层次，形成清晰的卡拉 OK 式进度反馈。
2. 普通 LRC 没有逐字时间轴时，会根据当前行到下一行的时间生成平滑的字符级估算进度，让桌面歌词也能逐字推进，同时不影响音频播放。
3. 逐字进度由 Android 原生时钟低开销刷新，并随暂停、继续、切歌和播放倍速实时校准。
4. 设置中新增“桌面歌词逐字高亮”开关；关闭后立即回退为整行显示。媒体通知和 Live Update/荣耀胶囊仍保持整行文本更新。
