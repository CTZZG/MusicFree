# MusicFree v0.15.0

听到喜欢的歌，也想看看它的 MV？现在可以在播放页直接打开，看完再接着听歌。

## 升级前请注意

- 需要 Android 14 或更高版本。Android 13 及以下请继续使用 v0.11.6。
- 直接覆盖安装就能保留歌单、设置和插件。先卸载会清空这些内容。如果以后想装回旧版，记得在升级前导出一份备份。

## 新功能

- 在播放页点「更多操作 → 观看 MV」，就能看到插件为这首歌提供的视频。封面旁出现「MV」时，点那里也能打开。
- 点「全屏」可以横着看。轻点画面能叫出控制条，暂停时也能拖进度，按返回键就回到播放页。
- 想换清晰度，点「MV 选项」。同一剪辑会从刚才的位置接着播。遇到不同剪辑，应用会先问你要不要从头看。
- 点「返回歌曲」，原来的播放进度和倍速都还在。
- 从 Wi-Fi 切到移动网络，MV 会停下来等你确认。想用流量看，先在「基本设置 → 常规」打开「使用移动网络播放」，再选择「本次允许」。

## 修复

- 修好了歌曲播放出错或播完后，有时换不了音质的问题。
- 修好了 MV 在全屏和播放页之间切换、或转动手机时，画面偶尔变黑的问题。

## 下载

大多数安卓手机选 **arm64-v8a**。拿不准就选 **universal**，这个安装包大一些。

32 位手机选 **armeabi-v7a**。**x86** 和 **x86_64** 供对应架构的设备或模拟器使用。文件校验值在 `SHA256SUMS.txt` 里。
