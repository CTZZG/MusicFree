# MusicFree v0.15.0

新增歌曲关联 MV 播放、横屏全屏观看与清晰度切换，并改进播放进度恢复、倍速保持与网络流量控制。

## 升级前请注意

- 需要 Android 14 及以上。Android 13 及以下请继续使用 v0.11.6。
- 直接覆盖安装即可。不要先卸载，卸载会清空歌单、设置和插件。
- 建议升级前导出并保留一份备份；如需回退旧版，请使用旧版导出的备份。

## 新功能

- 播放页支持观看支持该能力的插件所提供的 MV：在播放详情页点“更多操作 → 观看 MV”或封面旁 MV 入口即可选择播放。
- 支持横屏全屏播放与按比例自适应显示，退出全屏或切到后台时恢复原有屏幕方向；全屏下支持自动隐藏控制条与暂停后拖动进度。
- 支持在“MV 选项”或进度条画质标签处切换 MV 清晰度，同版本切换会保留当前播放位置；随时可点“返回歌曲”回到原歌曲暂停点，不混用 MV 进度。
- 默认限制移动网络加载 MV，避免大流量消耗；可在“基本设置 → 常规 → 使用移动网络播放”开启总开关后，于页面点击“用移动网络继续”单次授权。

## 改进与修复

- 观看 MV 期间或切换回原歌曲后，正确保留原有歌曲的播放倍速，不再被重置为默认速度。
- 播放出错、网络受限挂起或歌曲自然结束后的重试、切音质与续播更加可靠，不会误改已选音质或卡在不可拖动状态。
- 网络切换为受限状态时会及时停止 MV 数据加载，等待你手动确认后再恢复；返回原歌曲后可正常恢复播放。
- 改善画面切换与横竖屏旋转时的视频显示稳定性，如在移动网络切换等场景下仍有异常，可通过“基本设置 → 开发选项 → 复制播放诊断”反馈。

## 下载

大部分手机下载 **arm64-v8a** 版；不确定就下载 **universal** 版（体积较大）。

- `…-app-arm64-v8a-release.apk`：大部分手机
- `…-app-armeabi-v7a-release.apk`：32 位系统的手机
- `…-app-universal-release.apk`：通用版
- `…-app-x86_64-release.apk`、`…-app-x86-release.apk`：模拟器用

各文件的 SHA256 校验值见 `SHA256SUMS.txt`。
