# 🎵 MusicFree 0.7.2

0.7.2 重点收敛代码审计中发现的数据一致性、播放器生命周期和异步竞态问题，同时统一 WebDAV、插件安装与遥测的安全边界。并发下载、缓存、歌单/插件更新在失败时会保留可用旧状态；播放器启动和 MPV 服务重建更加稳定，迟到请求不会再把旧结果写回当前界面。

## 📱 下载

- [前往 MusicFree 0.7.2 Release 页面](https://github.com/CTZZG/MusicFree/releases/tag/v0.7.2)

Release 页面将提供 Universal、ARM64、ARM32、x86 和 x86_64 APK，以及 SHA256 校验、构建信息与混淆映射文件。

## 💾 数据与下载稳定性

1. 并发下载会原子预留目标路径，同名任务不再拿到同一个文件名。
2. MediaCache 淘汰在删除前校验当前值，刚写入的新缓存和新文件不会被旧淘汰任务误删。
3. 歌单删除先提交权威索引，再清理歌曲数据；索引写入失败时原数据仍可恢复。
4. 本地/网络插件升级先写入并提交新插件，旧文件最后再清理；新文件写入失败时旧插件继续可用。
5. 备份恢复报告按实际新增数量统计，重复条目不会被误报为新增。

## 🎧 播放器与歌词生命周期

1. 播放器启动增加就绪门控，后端锁定前不会触碰错误的 native adapter；MPV 冷启动不会先实例化 Nitro。
2. MPV Service 对空 Intent、销毁回调和排队命令进行收敛，服务重建或销毁后不会继续调用失效的 native 对象。
3. Artist、榜单、歌词搜索和 Markdown 异步解析加入 generation/取消保护，切换歌曲、标签或插件后只提交最新结果。
4. LyricManager 的 setup 幂等、订阅可释放，并只向当前活动的 MPV 或 Nitro 后端发送歌词更新。

## 🔐 安全与隐私

1. WebDAV 保存和建连统一强制 HTTPS，拒绝 URL 内嵌账号密码或不完整配置。
2. 插件下载、自动更新和 Deep Link 共用 HTTPS、公网地址与重定向校验；外部本地 JS 安装需要明确确认。
3. 遥测默认关闭，只有用户明确选择开启且远端配置允许时才初始化；关闭后立即停止上报。
4. 错误边界、媒体处理和下载日志不再输出完整媒体对象、URL 或错误上下文，环境变量模板只保留空占位符。

## 🔧 工程与兼容

1. CI 增加 `npx tsc --noEmit --pretty false` 和 High 级依赖审计门禁；锁文件完成非 `--force` 的安全升级，在线审计结果为 0 High / 0 Critical。
2. 修复 Gradle 对 `@expo/cli` 必须位于项目根目录的隐式假设，npm 嵌套依赖布局也能正常打包。
3. Android/iOS 版本名升级为 `0.7.2`，构建号同步升级至 `400021`。
4. 全量回归包含 71 个 Jest 套件、441 个测试，以及 Nitro 默认 FFmpeg/WMA、主应用 Kotlin 和禁用 WMA 回滚编译。

## ⚠️ 说明

- 仍有 18 项 Moderate 依赖风险需要跨主版本或破坏性升级，本版本没有使用 `npm audit fix --force`。
- 插件真正沙箱化、全局明文流量策略、targetSdk/SAF 迁移和 MPV 进程重建等真机/架构门禁仍需后续单独验证。
- 网络歌曲能否播放仍取决于插件返回的音频地址是否有效；本版本重点保证失败时不留下错误歌曲或不一致状态。
