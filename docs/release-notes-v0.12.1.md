# MusicFree v0.12.1

安装包更小，修复部分 MP3 / WMA 标签写入和界面原生初始化问题。

## 升级前请注意

- **仍需 Android 14（API 34）及以上**。Android 13 及以下请继续使用 v0.11.6 或更早的适用版本。
- Android 14 及以上请覆盖安装。不要先卸载旧版，卸载会清除应用里的歌单、设置和插件。

## 改进与修复

- **缩小安装包**：恢复 DEX 压缩、清理退役解码链和未使用模块，并裁剪未使用的代码。已验收的 ARM64 候选约 34.66MB，v0.12.0 同架构约 66.64MB；正式包大小以附件为准。
- **修复歌曲标签**：修复部分 ID3v2.3 MP3 / WMA 标签的反射读写缺失；写入 WMA 标题、歌手等字段时清除对应的旧大小写别名，避免其他读取器仍显示旧值，保留未修改的其他字段。
- **原生稳定性与维护**：修复界面原生监听器的并发初始化竞争，对齐 GIF 解码依赖，并独立整理播放取源职责。保留用户暂停、音频焦点和换音质位置保护规则。

## 下载

大部分手机下载 **arm64-v8a** 版；不确定时下载 **universal** 版（体积较大，包含所有架构）。

- `…-app-arm64-v8a-release.apk`：大部分手机
- `…-app-armeabi-v7a-release.apk`：32 位系统的手机
- `…-app-universal-release.apk`：通用版
- `…-app-x86_64-release.apk`、`…-app-x86-release.apk`：模拟器

各文件的 SHA256 校验值见 `SHA256SUMS.txt`，构建来源和签名记录见 `android-build-info.txt` 及正式构建日志。

## 验证范围

同一产品代码的实际 R8 Release 候选在 Android 14 模拟器完成 113 项全量检查和 36 项独立音乐库检查，覆盖播放、下载、迁移、锁屏、Doze、省电、重扫、移动改名、重复导入及权限撤销后恢复。MP3 / WMA 下载文件经独立标签读取与完整音频解码比对。Android 16 模拟器检查引擎进度、慢加载、暂停意图、换音质位置和冻结控制。

此前同机冷启动对照没有稳定提速结论，不把包体缩小解释为启动更快。模拟器和引擎检查不代表物理音频输出，本轮没有新增真机验收。
