## ⚠️ 升级提示

- **播放内核只保留 mpv。** Nitro 内核已移除，设置里的“播放内核”选项随之取消。**Google Cast 投屏和均衡器也一并移除**：两者都依附于 Nitro 的音频会话，而当前的 libmpv 没有编译音频滤镜，均衡器需要另行重建。
- **播放需要 Android 8.0 及以上。** 安装包仍声明最低 Android 7.0，Android 7.x 设备可以安装，但不在播放支持范围内。
- **设置、歌单等数据改存到应用私有存储。** 首次启动时会自动从旧存储迁移，已经写入的新数据不会被覆盖。建议升级前在侧边栏“备份与恢复”中先备份一份（备份包含歌单与插件，不含设置），升级后确认歌单与设置完整。
- **插件不再经过能力审批。** 插件与应用运行在同一个环境中，原有的能力限制无法真正隔离插件，反而让许多上游可用的插件无法加载。现在插件按可信代码运行，安装时不再弹出能力确认。请只安装可信来源的插件。应用自身的 WebDAV 备份仍走受限通道。

## 🔄 重点更新

### 播放

- 新增“切歌淡入淡出”（设置 → 基本设置）：上一首末尾淡出、下一首开头淡入，可调淡化时长，两首歌不会重叠出声。
- 新增 Last.fm 播放记录（实验性）：需要自行申请并填写 API Key 与 Secret，离线时会排队、恢复网络后补发。完整的授权流程尚未在真机上验证。
- 后台连续播放更稳：mpv 一次准备多首后续曲目，系统在后台冻结 JS 时也能接着播放；切歌期间保持唤醒锁，不会再出现后台播到曲尾就停住。
- mpv 的内存解复用缓存固定为 32MB，避免切歌瞬间内存暴涨导致进程被系统结束。
- 锁屏、通知和灵动岛可以显示 http 地址的封面（此前一律显示默认图标）。
- 移除 Nitro 后，实测安装包从 49.8MB 降到 41.2MB，内存占用约降低 30MB。

### 搜索

- 一个来源慢或失败不再影响其他来源：任一来源返回后就显示结果；超时的来源在标签上显示“超时”，可以单独重试。
- 修复换关键词再搜后，之前打开过的专辑等类别混入上一次搜索结果的问题。
- 翻页失败后点“重试”只补加载失败的那一页，已经加载的结果会保留（原来会回到第一页并清空列表）。
- 失败提示区分响应超时、插件已卸载或禁用、返回无法识别的结果和插件异常。

### 本地音乐与歌词

- 扫描结束后可以查看扫描结果：哪些文件被跳过、原因是什么。
- 文件元数据按路径与修改时间缓存，重复扫描更快；标签缺失时按文件名推断标题和艺术家；导入时保留已有的封面与时长。
- 新增歌词编辑：播放中逐行“打点”设置时间、微调偏移，保存为本地歌词。

### 插件

- 插件的模块行为恢复与上游一致：引用不存在的模块时返回空值而不是报错，并提供真实的库对象，修复 crypto-js 的 AES/DES 等调用报错。
- 修复所有插件的推荐歌单都显示“出错啦”的问题。
- 插件管理页可以“复制诊断记录”，便于反馈插件问题。

### 界面与无障碍

- 读屏（TalkBack）下，按钮、开关、列表项、播放控制和歌词行都有朗读文本；拖拽排序提供上移、下移等替代操作；歌词滚动遵循系统“减弱动效”设置。
- 修复切换页面时的黑闪。
- 修复进入播放详情页时，底部播放条在转场期间压在新页面上的问题。
- 修复面板接连打开时界面卡死，以及键盘遮挡面板里输入框的问题。

### 稳定性与安全

- 设置、歌单等数据改为原子写入的文件存储，修复设置修改后重启又还原等静默丢失问题。
- 依赖安全更新：axios 1.20.0、qs 6.16.0、React Navigation 7.23 等，处理了生产依赖中所有有修复版本的高危与中危公告。
- 发布构建新增质量门：类型检查、代码检查、单元测试与补丁校验通过后才会打包；依赖审计只放行上游暂无修复、且不进入安装包的两项构建工具公告（node-forge、image-size）。
