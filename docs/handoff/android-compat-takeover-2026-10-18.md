## 已确认并修复的原生 API 检查漏报

旧 `check-api-floor.py` 分别检查符号名字和版本节点，把 `@version` 丢掉。
用真实 NDK 生成只依赖 `libc.so`、导入 `malloc@LIBC_N` 的 ELF：API 24 的 libc 有 LIBC_N 节点，
但 malloc 只导出为 `malloc@@LIBC`，所以实际不能绑定；旧检查器仍返回无问题。

检查器现保留并匹配每个导入符号的版本。自检新增实际链接的错误版本 ELF，5 个 fixture × 4 ABI
在本地 NDK 27.1 通过，原 AAR 四架构静态检查继续通过。弱 memfd_create 仍只作可缺失项报告，
没有以删除弱符号或提升 minSdk 来消除报告。静态检查不证明 Java API、弱调用运行时保护或完整应用行为。
