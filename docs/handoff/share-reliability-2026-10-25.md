# 分享可靠性与性能基线

本轮来自用户“按建议顺序实施”，承接 PR57 的歌曲/歌词分享、歌词呈现与首页整理。PR57 历史 #212 的测试编排失败已由 #213 验收；本轮不把它说成新的产品故障。分享详情请求无限等待是另一个本地可复现的边界问题。

## 决策与实现

- 复用现有 `withTimeout`，仅给分享用的插件公开详情页请求设置 3 秒期限；超时、拒绝或抛错均降级为歌名/歌手。播放取源 15 秒、备用来源 8 秒、250ms/.25s 和暂停窗不变。
- 分享面板区分准备、保存与系统分享阶段。准备阶段可取消并立即重试；每次操作独占一个 token，取消/关闭后的迟到结果既不能提交原生操作，也不能解除后来请求的 busy。已经开始的相册写入或系统选择器不伪装成“可撤回”。不取消第三方插件内部执行；忽略其迟到结果。
- 同一帧连续点击只启动一次。分别提示图片生成、附件文件、保存和系统分享失败；错误日志只含静态 action/reason，不写原始插件错误、URL、歌词全文或图片 Base64。缺详情 URL 的正常文字降级不显示失败提示。
- 取消系统图片分享时清除本次未交给接收方的缓存；接收方已经选定则保留，沿用最多 20 份/24 小时的原清理策略。相册、ShareImageStore、播放/歌词时钟和依赖不变。
- 长曲逐曲续听和 Mesh 仍未纳入本轮。版本保持 0.13.1/400036，最低 API34。不合并或发布。

## 验证方法与范围

真实 TS/Jest 覆盖不回应插件的 3 秒降级、拒绝/抛错、迟到 URL；真实面板覆盖重复点击、取消后重试的旧结果隔离、关闭后忽略、SVG 5 秒失败、原生保存完成前保持 busy、安全分项失败提示。临时 native 边界不是 Android 运行。布局在小屏/横屏、三语、1–2 倍字体下额外执行“准备→取消”的真实组件交互。

`e2e/share-receiver` 只是一份独立 UID 的测试 APK，不进入产品、不增加生产权限。SDK javac/D8/aapt2/zipalign/apksigner 真实构建；接收 ACTION_SEND 的 content URI 后，在没有媒体/存储权限的情况下读取 PNG，后台发送方期间延迟 5 秒再读，独立记录 UID、授权、字节与 SHA256。宿主重新解码拉回图片并检查远程双色封面、选中歌词。另验证缺失附件被拒、取消选择器后可重试、接收后返回原面板。接收器只声明对 MusicFree 的 package 可见性，便于核对不同 UID；debuggable 仅用于拉取测试接收方自有结果，不改变 MusicFree 的 Release 属性。

宿主检查器/编排有负例，但不替代 Android 真正授权验证。只有设备工作流真的运行成功、附件独立重算后才填写结果。尚无真实手机第三方接收应用、实体 ARM、物理音频或后台耗电结论；不能把模拟器接收器称作微信等应用验收。URI 授权只验证接收 activity 存活时的延迟读取，不宣称 Android 在 force-stop 或接收方结束后仍保留临时授权。

## 性能顺序

复用 `e2e/perf.sh` 和 `e2e/perf-cold-compare.sh`，不要另造一套打点或改窗口。

1. 当前产品一次必要 Beta 全量回归通过后复用同 APK，运行完整 perf，记录冷启动、固定本地测试源搜索、在线/本地点歌各预热 1 次和 10 次有效样本。独立核对全部原始指标，不从引擎开始推进推断扬声器出声，也不将本地 fixture 搜索视为公网插件耗时。
2. 另一次 E2E-only 对照复用旧 Beta212（run40169209040，产品637b）与新候选，旧→新→旧、同一硬件加速模拟器、每组清数据并重新安装/准备、预热1+有效10，源提交/APK hash/真实 home-drawn 全部齐全。完整对照不设速度门；缺组或缺样本失败，不补样本、不拿快的一组充完整结果。
3. 观察 median/P95 与旧前后波动再定位热点。本轮分享补丁并不承诺缩短冷启动；不从文件变少、包变小推断更快。歌词滚动帧时/耗电需真实 ARM 手机，模拟器结果只能用于本轮模拟器对照。
4. 之后优先只读播放信息，再根据实际录屏定位播放页/迷你条跳变；复用现有 adapter、导航、封面代际、播放意图所有权，不另建播放状态。原有 SDK/native 缺失字段明确未知，插件质量标签与实测音频参数分开。

当前本地 SDK 已编译接收器，未执行新 App 的完整本地 Android 构建或设备运行；本轮云端结果应记录在 PR 描述与外部 progress.json，避免纯文档移动产品 head 取消运行。共享依赖临时 link 使用，不 npm ci 改共享目录。首次 lint/布局边界测试的失败与修正日志保留，不当成产品设备失败。
