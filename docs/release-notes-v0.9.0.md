# 🎵 MusicFree v0.9.0

## 📱 下载选项

**推荐下载（Android 8.0 及以上）：**

- **Universal APK**：前往 [MusicFree v0.9.0 Release 页面](https://github.com/CTZZG/MusicFree/releases/tag/v0.9.0) 下载 `MusicFree-0.9.0-<短 SHA>-app-universal-release.apk`

**按设备架构下载（体积更小）：**

- **ARM64（推荐）**：`app-arm64-v8a-release.apk`，适用于大部分现代 Android 设备
- **ARM32**：`app-armeabi-v7a-release.apk`，适用于较老的 Android 设备
- **x86_64**：`app-x86_64-release.apk`，适用于 x86_64 模拟器
- **x86**：`app-x86-release.apk`，适用于 x86 模拟器

Release 页面同时提供 SHA256 校验文件、构建信息与混淆映射文件。

## ⚠️ 升级提示

- **界面整体改为 iOS 风格，侧边栏取消。** 底部改为首页、搜索、资料库、设置四个标签。原来侧边栏里的入口（基本设置、插件管理、主题、备份与恢复、定时关闭、语言、检查更新、退出等）都在“设置”标签里；首页原来的“我的音乐”移到了“资料库”标签。
- **主题只保留浅色和深色，默认跟随系统。** 用过“液态硅胶”或自定义配色的，升级后自动改为跟随系统，自定义颜色不再保留；明确选过浅色或深色的保持不变。自定义背景图保留，但只在首页显示。
- **播放页默认是圆角卡片封面。** 喜欢原来铺满顶部的大图，可以在 设置 → 外观 → 封面样式 中选“沉浸大图”；圆形唱片也仍可选。
- 应用内的“检查更新”读的是上游 maotoumao/MusicFree 的版本信息，不会提示本分支的新版本，请在本仓库 Release 页面下载。

## 🔄 重点更新

### 导航与外观

- 底部悬浮的毛玻璃标签栏，键盘弹出时自动收起；在非首页标签按返回键回到首页标签。
- 迷你播放器浮在标签栏上方：圆形封面、歌名和歌手两行、细进度条、播放/暂停与播放列表按钮；进入二级页面时平滑移到底部。
- 新的 iOS 配色、字号、导航栏（居中标题、左侧返回箭头）、开关、按钮、分组列表与分段控件。

### 首页与搜索

- 首页改为大标题布局：继续听卡片、推荐歌单、榜单、最近播放；右上角切换推荐歌单和榜单使用的音源，选择会被记住。
- 搜索成为底部标签：没输入时显示“搜索”大标题，圆角搜索框带清除按钮，正在输入或已有结果时出现“取消”。再点一次搜索标签会聚焦搜索框。
- 从播放页点歌手、专辑，或从外部传入关键词时，会回到主页并切到搜索标签开始搜索；同一个关键词再搜一次也会重新执行。

### 资料库与歌单

- 资料库标签集中了本地音乐、下载（显示正在下载的数量）、播放历史、智能歌单、收藏歌单，下面是“我的歌单”网格，可导入、新建、编辑，长按删除。
- 歌单、专辑、榜单页改用居中大封面头部；“播放全部”拆成“播放”和“随机播放”，随机播放只打乱这一次的播放列表，不改变设置的播放模式。
- 播放记录、本地音乐等列表的行拼成一张分组卡片；歌单浏览页的“我的歌单 / 收藏歌单”改为分段控件。

### 播放页

- 圆角卡片封面带投影；歌名 24pt 粗体，右侧是收藏与更多按钮。
- 进度条下方左右是已播放和剩余时间，中间是音质与倍速标签，点按即可切换。
- 上一首、播放/暂停、下一首放大居中；最下面一排是播放模式、歌词、下载、评论、播放列表。上滑切换下一首的手势保留。
- 顶部改为收起按钮与“正在播放”；播放页从底部升起。

### 设置、弹层与提示框

- 设置标签顶部是应用卡片（点一下检查更新），下面按常用、通用、插件与数据分组。
- 基本设置的每个分区拼成一张分组卡片，顶部的分区跳转改为胶囊按钮。
- 提示框改为 iOS 样式：标题居中，按钮去掉色块，两个以内并排、更多时竖排；底部弹层顶部加上小横条。

### 通知

- 修复 Live Update 通知不显示歌曲封面：封面请求允许跟随跨域名的重定向（不携带凭据），网络失败或服务端临时错误时按 2、5、15、30 秒退避重试，并跳过已经过期的请求。

### 依赖与发布

- 新增 `@react-navigation/bottom-tabs` 7.16.2（与现有 `@react-navigation/native` 7.2.5 配套），移除 `@react-navigation/drawer`。
- 发布审计新登记 braces（GHSA-vfj7-8cjw-p6xm）例外：上游最新的 3.0.3 仍受影响、暂无修复版；它只在打包时匹配仓库自己的路径规则，不打进安装包。上游发布修复版后审计会自动提醒升级。
