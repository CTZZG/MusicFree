# 🎵 MusicFree 0.6.8

0.6.8 是一次以**界面重构、性能治理、数据安全和发布可靠性**为重点的稳定版本。本次不仅重新设计了首页快捷入口对应页面，也集中修复了歌单保存、本地文件扫描、智能歌单卡顿、外部插件安装和 Release 签名门禁等问题。

## 📱 下载

- [前往 MusicFree 0.6.8 Release 页面](https://github.com/CTZZG/MusicFree/releases/tag/v0.6.8)

Release 页面将提供：

- **Universal APK**：适用于大多数 Android 设备
- **ARM64 APK（推荐）**：适用于大部分现代 Android 手机和平板
- **ARM32 APK**：适用于较老的 Android 设备
- **x86 / x86_64 APK**：适用于对应架构的模拟器
- `SHA256SUMS.txt`、构建信息和混淆映射文件

## ✨ 界面与交互

1. 重构快捷入口对应页面，统一本地音乐、下载管理、历史记录、推荐歌单、智能歌单、歌单管理和音源管理的视觉语言。
2. 优化快捷页面顶部区域、卡片层级、留白和横屏安全区，减少文字贴边和布局拥挤。
3. 移除页面和 AppBar 重复绘制的全屏渐变/模糊背景，修复顶部白色断层、渐变错位及浅色主题白字问题。
4. 音源管理的插件列表、排序、订阅和 LX 音源页面统一使用新的透明宽松顶部栏。
5. 空列表增加明确空态，不再出现没有任何提示的空白页面。
6. 动效开始遵循系统“减少动画”设置，并缩短顶部菜单动画时间。

## 🧠 智能歌单

1. 新增推荐、最近播放、最近添加、常听、收藏、本地音乐和已下载音乐等智能分类。
2. 支持按歌手、专辑和音源聚合；默认显示摘要，并可展开查看全部结果。
3. 将静态曲库索引与动态播放评分分离，缓存重复计算结果，减少进入页面和自动切歌时的主线程停顿。
4. “最近添加”兼容本地导入、下载和歌单中的多种时间字段。
5. 过滤缺少关键身份信息及已经脱离本地曲库的明显无效歌曲。

## ⚡ 性能优化

1. 本地文件状态检查统一使用共享解析器，最大并发限制为 6，并支持相同路径请求去重。
2. 成功和缺失文件使用不同缓存时间，最多保留 4000 条状态并按 LRU 淘汰。
3. 下载进度每 500ms 更新时，不再重复扫描全部已完成文件。
4. 本地封面缓存增加容量上限、失败短 TTL 和路径级精确失效。
5. MediaCache 改为小批量异步清理，避免一次同步删除数百条缓存造成卡顿。
6. 音源管理由父列表统一读取诊断日志，避免每张插件卡片重复解析同一份 MMKV 数据。
7. 首页发现模块增加请求超时，异常插件不会长期占用加载状态。

## 🛡️ 数据与播放稳定性

1. 修复歌单管理切换“我的歌单/收藏歌单”时，旧列表可能被保存到错误标签的问题。
2. 歌单保存改为等待持久化成功后再更新界面和清理删除数据，避免存储异常造成歌曲丢失。
3. 未保存编辑在切换标签或退出页面时提供“保存 / 不保存 / 取消”。
4. 修复删除歌单歌曲后数量可能不更新的问题。
5. 文件选择器增加异步 generation，旧目录结果不会覆盖用户刚打开的新目录。
6. 修复播放列表补充元数据后标题、歌手、专辑和封面不刷新的问题。
7. 修复列表复用时可能短暂继承上一首歌曲“文件不存在”或图片加载失败状态的问题。
8. 播放条点击改为手势确认结束后进入详情，左右滑动切歌增加并发保护。

## 🔐 安全与发布

1. 浏览器或其他 App 通过 Deep Link 请求安装插件/LX 音源时，必须显示来源、HTTPS 地址和第三方代码风险，并由用户确认。
2. 拒绝 HTTP、内嵌账号密码、localhost、环回、链路本地和常见私网安装地址。
3. 备份恢复中的网络插件地址使用相同安全校验。
4. 移除全局 MMKV 对象暴露。
5. MPV MediaBrowser 仅向系统认可的可信媒体控制方开放。
6. 正式 Release 缺少签名、密钥校验失败、APK 验签失败或证书指纹不匹配时立即终止。
7. 未签名 Beta 包会明确标记为 `UNSIGNED-TEST-ONLY`，避免与正式包混淆。
8. 升级 Axios、WebDAV 和 Application Insights 依赖链，生产依赖 Critical 漏洞降为 0。

## 🔧 工程与测试

1. Nitro 格式扩展审计适配 `react-native-nitro-player@1.4.3`。
2. 补充 M4A/ALAC、WMA/ASF、DSF 和常规音频格式样本矩阵。
3. Release Action 强制执行 TypeScript、全量 Jest、Nitro 静态审计、patch-package、Critical 依赖审计和 diff 检查。
4. 全量 **54 个 Jest 套件、350 个测试**通过。
5. Android Release 构建、ARM64 真机升级安装、冷启动和 APK 固定证书验签通过。

## ⚠️ 说明

- 插件仍属于第三方代码，请仅安装可信来源提供的插件。
- 本版本没有变更 Android 权限模型；本地音乐较多的用户首次校验文件状态时仍可能需要一定时间。
- MPV 后端启动内存仍高于 Nitro，后续版本将继续评估播放器延迟初始化方案。
