# 🎵 MusicFree 0.6.9

0.6.9 是一次以**播放详情视觉、歌词体验、MPV 一致性和快捷页面可用性**为重点的增强版本。本次将播放详情改为真正的全屏沉浸主视觉，让无封面歌曲在不拖慢列表和播放的前提下获得更完整的展示；同时为播放页歌词和 Android 悬浮歌词补齐平滑切换与真实逐字高亮。

## 📱 下载

- [前往 MusicFree 0.6.9 Release 页面](https://github.com/CTZZG/MusicFree/releases/tag/v0.6.9)

Release 页面将提供 Universal、ARM64、ARM32、x86 和 x86_64 APK，以及 SHA256 校验、构建信息与混淆映射文件。

## 🖼️ 播放详情与封面

1. 竖屏方形封面模式改为从状态栏区域开始铺开的全宽 Hero 主图，并向下自然渐隐到播放背景，不再叠加独立大封面卡片。
2. 歌名、歌手、平台和收藏入口直接落在主图渐隐交界区；圆形唱片模式和横屏双栏布局继续保留原交互。
3. 只有进入播放详情且当前歌曲确实缺少封面时，才调用所属音源及少量已安装音源进行严格匹配补图。
4. 可选接入 TMDB 艺人背景作为仅限详情页的 backdrop；它与歌曲 cover 分层，不写入播放队列、列表、通知栏或 MMKV。
5. 补图查询设有 3 秒总时限、最多 2 个并发、请求去重、艺人级长缓存和失败冷却，慢音源不会阻塞播放与页面操作。
6. 搜索兜底要求歌名完全一致且歌手兼容，避免把同名翻唱、Remix 或无关歌曲的图片误认为当前封面。
7. 异步结果绑定歌曲身份，快速切歌时旧请求不会覆盖新歌曲；详情补图不写入播放队列或 MMKV。

> TMDB 为可选能力：Release 构建可配置 `TMDB_READ_ACCESS_TOKEN` 或 `TMDB_API_KEY` 仓库 Secret。未配置时自动降级到已安装音源补图；任何模式都不会在首页、列表或后台发起该请求。

## 🎤 歌词体验

1. 播放页 Mini 歌词在换行时以 280ms 完成旧行淡出上移、新行淡入归位，节奏更接近参考效果。
2. 完整歌词当前行同样增加淡入和轻位移动画，但不改变行高、边距和 FlatList 布局，避免自动滚动抖动。
3. Mini 歌词仅为当前行前后最多 3 行创建动画节点，长歌词不会因逐行 Reanimated 状态造成额外卡顿。
4. 动效继续遵循系统“减少动画”设置。
5. 切入完整歌词页时先从带歌曲身份和序列号的同步进度快照完成首帧定位，再异步校正原生进度，不再停在 0 秒等待下一次回调。

## ✨ Android 悬浮歌词逐字高亮

1. 支持使用歌曲自带或音源提供的真实逐字时间轴进行高亮。
2. JS 只在换行、暂停/继续、拖动进度和切歌时发送一次时间表；后续进度由原生时钟以低开销推进。
3. 暂停时高亮立即停住，继续播放从当前进度恢复；同一歌词行内拖动进度也会立即重新定位。
4. 切歌、无歌词或逐字数据缺失时会清理旧状态并自动回退为整行文本，不伪造逐字时间。
5. 媒体通知和 Live Update 歌词仍保持整行更新，避免系统通知被高频刷新。

## 🧭 快捷页面可用性

1. 修复快捷入口页面顶部菜单、返回、搜索等按钮点击无响应的问题。
2. 根因是自定义状态栏透明背景与 AppBar 处于同一高层级并参与触摸命中；现在状态栏、渐变、图片和液态背景统一为非交互视觉层。
3. 增加覆盖层回归测试，防止后续新增绝对定位背景再次吞掉顶部按钮操作。
4. 延续 0.6.8 后续修复：歌单管理标签切换即时响应，主题局部纯色色块得到清理，液态硅胶主题可清除自定义背景图。
5. 修复首页抽屉顶部侵入状态栏、播放条覆盖抽屉、返回手势直接退出桌面和离开后抽屉状态残留的问题。

## 🎧 MPV 播放一致性

1. 修复 MPV 在自然结束边界已经播放下一曲、但 UI、歌词和播放列表仍停在上一曲的问题。
2. 原生端会等待 `START_FILE/FILE_LOADED` 与 playlist position 共同确认 prepared promotion；未确认音频会停止并交回 JS 显式加载。
3. 重复预备同一首歌改为幂等操作，避免封面补齐或音源预解析反复替换 token。
4. 自然提升后 TrackPlayer 再读取一次后端 active identity，确保播放条、详情页、歌词、历史和通知使用同一歌曲身份。

## 🔧 工程与兼容

1. Android `versionCode` 升级至 `400018`，Android/iOS 版本名同步为 `0.6.9`。
2. 新增播放详情补图缓存/匹配、悬浮歌词 payload、歌词动画策略和非交互覆盖层测试。
3. 保留 Nitro 与 MPV 双后端，不改变现有播放队列、媒体通知和 Live Update 的决策逻辑。
4. Android 逐字悬浮歌词保留旧整行 bridge 作为兼容回退。

## ⚠️ 说明

- 网络补图质量取决于当前歌曲所属音源；音源无详情/搜索能力或网络不可用时显示默认封面。
- 只有真实逐字歌词才能显示准确逐字高亮，普通 LRC 会按整行显示。
- 首次加载远程图片仍受网络和图片服务器影响，但不会阻塞音频播放或页面交互。
