# MusicFree v0.11.5

改善冷启动、加载时暂停、下载换源和本地音乐导入，修复通知状态及歌词、封面处理问题。

## 下载

需要 Android 8.0 及以上。大部分手机下载 **arm64-v8a** 版；不确定时下载 **universal** 版（体积较大，所有架构通用）。

- `…-app-arm64-v8a-release.apk`：大部分手机
- `…-app-armeabi-v7a-release.apk`：较老的 32 位手机
- `…-app-universal-release.apk`：通用版
- `…-app-x86_64-release.apk`、`…-app-x86-release.apk`：模拟器

各文件的 SHA256 校验值见 `SHA256SUMS.txt`。

## 改进与修复

- **下载可以使用已记住的备用来源**：原来源取不到下载地址时，尝试播放时记住的同一首歌的备用来源。设置中可单独关闭；下载详情显示实际来源和音质，文件名和标签仍按原歌曲保存。
- **本地音乐导入更可靠**：重复扫描或从文件夹导入相同文件不再新增重复条目。撤销音频读取权限后不再误报“文件不存在”，点歌时会请求权限，恢复权限后可继续播放。
- **换音质保留实际停下的位置**：在替换音源前捕获最新进度，保留等待期间的播放和拖动结果，减少回退；修正音频输出启动时的进度估算，避免进度短暂落在恢复起点之前；内部恢复进度时保持加载状态，主动暂停和临时音频打断仍然生效。
- **加载圈也能按暂停**：播放页和迷你播放器加载、缓冲时可直接点击加载圈暂停，之后点播放可以恢复。
- **冷启动减少固定等待**：移除开屏页首帧同步的一秒超时。实际启动收益随设备变化，本次不承诺固定缩短一秒。
- **通知与播放状态保持一致**：合并短时间内过密的通知更新，保留最后一次状态；播放服务晚创建或重建时补齐当前歌曲、进度和状态，避免媒体控件停在无状态或显示滞后。
- **封面和歌词处理更稳妥**：降低长 OGG 文件写入封面时的内存占用，修复桌面歌词无效颜色和颜色名称解析问题，清理缓存时同步清理罗马音。

## 验证范围

本次产品改动已在 Android 14 模拟器完成播放、下载、数据迁移及锁屏、Doze、省电回归；Android 16 模拟器检查实际引擎进度、暂停意图、慢加载、页面控制和播放服务启动。冷启动、加载时暂停及其他视频应用打断后恢复的真机结果来自用户反馈。模拟器状态与引擎位置检查不代表物理音频输出验证，厂商后台限制仍未系统验收。新增 AudioTrack 时钟修正的真机表现尚未独立验证，不将此前用户对旧候选的反馈视为新库验收。
