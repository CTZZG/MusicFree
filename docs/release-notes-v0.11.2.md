# MusicFree v0.11.2

修复版本：开着代理软件的“系统代理”时通知栏封面显示不出来，菜单收起和页面切换叠在一起。

## 下载

需要 Android 8.0 及以上。大部分手机下载 **arm64-v8a** 版；不确定时下载 **universal** 版（体积较大，所有设备通用）。

- `…-app-arm64-v8a-release.apk`：大部分手机
- `…-app-armeabi-v7a-release.apk`：较老的 32 位手机
- `…-app-universal-release.apk`：通用版
- `…-app-x86_64-release.apk`、`…-app-x86-release.apk`：模拟器

各文件的 SHA256 校验值见 `SHA256SUMS.txt`。

## 修复

- **开着代理软件的“系统代理”也能显示封面**：FlClash 等代理软件开启“系统代理”后，通知栏和锁屏上的歌曲封面显示不出来。现在会经过代理正常加载。
- **菜单收起后再切换页面**：页面右上角菜单里的选项，现在等菜单收起后再执行。从插件管理进入“订阅设置”时，菜单收起和页面切换不再叠在一起。
